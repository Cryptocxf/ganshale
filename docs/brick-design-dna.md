# 搬砖收藏展台 · Design DNA

已确认方向：温暖、克制、有触感的3D收藏展台。参考来源为用户提供的界面图，非第三方品牌模板。

## 真实资源
- 应用标识沿用项目现有品牌；页面金字塔标记由同套砖块素材构成。
- public/brick-scene-clay-v3.png：原创生成透明图集，4×4等格；前13格为砖块，末3格为人物。
- 砖块参考原始孔型与石材纹理，人物为原创黏土3D形象，不再使用emoji或手绘线条替代。
- 新素材通过SVG视口或Canvas原图裁切引用，不能以整张概念界面图充当页面。

## 版式
- 主导航右侧：月/年、周期、刷新、下载。
- 标题、说明、金字塔及人物统一在同一展台内。
- 右上独立故事浮卡，可收起；底部横向图鉴，单屏展示。
- 正文字体、标题字体、页面背景和卡片背景沿用客户端主题变量。
- 素材质感为主视觉；边框、阴影克制，不做持续动画。

## 数据与验证
- 一天一砖，以真实工时排序；图鉴等级与素材索引唯一对应。
- 原图集透明边距需裁切，避免层间悬空；年度图以缩放保持数据完整。
- 实际截图使用隔离测试目录的示例数据，不能当作用户真实记录。
- 两个窗口尺寸检查图鉴保持一屏；需继续验收空态、年度密集状态及切换主题。
- huashu-design流程：方向已确认，本轮为真实组件中途审阅，尚未最终视觉验收。
