# 干啥了 Didly v2.1.0

发布日期：2026-11-26

## 更新内容

- 改用可收展的左侧导航，收起后保留图标及悬停名称；模型、提示词、时间、主题和关于直接进入对应页面。
- 优化每日看板卡片比例、表格列宽与图例布局，适配抽屉展开和收起。
- 办公总时长增加海水水位与点击波纹；水位按累计时长分八段增长，10 小时封顶，计时不封顶。
- 优化上下班时间选择，提供紧凑六项滚动列表并定位到已保存的时间。
- Logo 支持居中查看大图、右键复制和居中复制成功提示。
- 原生窗口按钮背景透明，改善启动页与不同主题的一致性。
- 移除独立“数据”页面功能，保留历史记录和其他页面统计。
- 修复损坏的待恢复窗口记录缓存导致客户端启动失败的问题。

## 安装说明

- Windows x64 安装包，未进行代码签名；Windows 可能显示安全提示。
- 保留原有本地数据；建议更新前备份重要记录。
