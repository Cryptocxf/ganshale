# 工时积木：时间柱状图

替代原有金字塔与13级图鉴，不变更真实计时、窗口采集、数据库或报告生成口径。

## 新规则
- 月：有工时日期按1日至月末从左到右，零工时不占列；实心砖数=ceil(日工时秒数/3600)。最后不足一小时也占一砖。
- 年：始终12个月份列，按月份排列；每个有工时日期一块多孔砖，同月按日期从下往上叠放，与当天小时数无关。
- 内部编号：月为date:hour:n，年为date:day，确保同一天多块小时砖可独立选中。
- 默认不展示故事、不选中砖。点一块显示，再点同一块关闭；点另一块切换。
- 仅选中砖发光：工作日暖光、普通周末蓝光、已核实节假日红光；调休和未知年份沿用brickRestDay规则。
- 月视图每块小时砖显示所属日期、当日第几块及该砖对应时长；工作总结和应用排行属于当天，不伪造逐小时内容。
- 保留当前背景切换、白领人物和十档气泡、纯文字操作、16:9下载/复制。旧材质图鉴和入口移除。
- 固定比例导出采用相同柱状图；有选中砖时带选中高亮和当天故事/应用排行；未选中时保留周期复盘摘要。

## 主要文件
- src/lib/brickChart.ts：纯计数与坐标布局函数。
- src/lib/brickArtwork.ts：画布图表/选中发光/导出。
- src/components/BrickDashboard.tsx：按需故事及点击开关。
- src/components/brickDashboard.css：全宽图表与右侧按需浮卡。
