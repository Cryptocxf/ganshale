# 休息日工时砖标记

依据：国务院办公厅关于2026年部分节假日安排的通知（国办发明电〔2025〕7号）。
来源：https://www.xinhuanet.com/politics/20251104/88bcffd88ae249e58c699b8772548e3d/c.html

- 日历固定保存在 src/lib/brickRestDay.ts，可离线使用。
- 2026年七个公布放假区间共33天，有工时则红色柔光；这里是公布的放假区间，不用于法定加班工资计算。
- 普通周六周日有工时为蓝色柔光；六个调休补班日不标休息日；放假与周末重合以节日红光优先。
- 未核实年份/无效日期返回unknown，不猜测农历节日或调休安排。新年份需按官方通知补充数据，目前不承诺自动联网更新。
- 日期分类只用于展示，不改计时口径、采集、数据库记录、工作日调度或AI提示词。
- 故事卡保留日期、工时、等级、完整总结和应用排行，增加节日名称/周末说明及休息提醒。
- 光晕静态绘制，不加入闪烁或循环动画。客户端与导出共用drawBrickTower，复制和下载同步。
- scripts/test-brick-stats.cjs：七节日、全部补班日、周末重合优先级、33天覆盖、未知年份及无效日期通过。
- scripts/test-brand-wordmark.cjs：隔离数据库春节记录/故事文案、四种桌面尺寸、无页面滚动、图鉴留白、导出与复制一致性通过；截图.private/brick-holiday-story.png。
- npm run build、改动文件ESLint通过；构建仍有既有大chunk警告。
- 不打包、不发布、不修改用户真实记录。
