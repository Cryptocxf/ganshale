# 工时积木批准版落地

按用户确认的收藏展台预览实施，仅影响工时积木页及它的绘制器；没有修改导航、其他页面、原生采集、统计口径、AI 调度或存储结构。

## 视觉规则

- 复用 frontend-design-codex 工作流及原主题变量：中性客户端背景、白色卡片、局部暖石色展台；主操作使用局部深青色，其余操作降级。
- 精简标题区；项目 logo 和干啥了／Didly 双行字标保留。本月、本年、下载图片入口不变。
- 展台突出记录日及真实工时；日期和等级继续直接绘在原正面砖素材上，保留原白领人物和13级图鉴。人物状态仍按已有累计工时条件选择，不为模仿概念图而伪造疲惫状态。
- Canvas 根据展台实际 CSS 尺寸和设备像素密度绘制；ResizeObserver 只管显示，不参与业务计时；点击坐标与显示尺寸一致。海报继续保留16:9和9:16独立重排。
- 故事区小砖图左置、日期／工时／等级带图标右置；工作总结全文不截断、不设置行数上限、不提供展开按钮。
- 五行排行保留序号、logo及每日同源配色；列表按剩余高度分配行距。极长总结不压缩成难读字号，允许故事区纵向滚动，所有内容和五行排行均可到达；普通总结常用桌面尺寸无需滚动。
- 周期之最与图鉴详情入口保留，避免以美化为由删除功能。

## 文件

- src/components/BrickDashboard.tsx：布局及响应式画布显示。
- src/components/brickDashboard.css：清理叠加覆盖，统一局部样式、响应式及主题映射。
- src/lib/brickArtwork.ts：增加仅客户端使用的展台铺放模式，默认海报模式不变。
- scripts/test-brand-wordmark.cjs：隔离 Electron 显示、交互、边界及导出测试。
- scripts/test-brick-stats.cjs：补全品牌测试桩常量，统计断言保持不变。

## 验证与限制

- TypeScript/Vite 构建通过；仍有既有大 chunk 提示。
- 相关 TS/TSX ESLint 通过；工时积木日期边界、去重、等级及0–366块布局回归通过。
- 隔离 Electron 检查1366×768、1440×900、1920×1080、1120×760：普通全文总结和五行排行在卡片内，无滚动。
- 1024×768和480×900检查无页面横向溢出；窄屏允许竖向排布和滚动，不宣称仍保持桌面单屏。
- 深色、纸张和默认皮肤检查基础文字／背景区分及无横向溢出，不等于所有现有皮肤完成对比度验收。
- 检查本月展示、完整总结、周期详情、两种PNG尺寸、Canvas绘制像素及砖块命中坐标；本年入口和数据查询沿用既有逻辑，本轮没有重新完成数百日年度模式的整套界面回归。
- focus-visible通过浏览器伪状态检查；隐藏离屏窗口不支持真实系统键盘焦点，因此未把它记作物理键盘全流程通过。
- 测试用独立 appData，不读写用户历史数据。截图使用软件合成，避免 Electron 离屏 GPU 画布图层漏拍；未修改正式客户端 GPU 配置。
- Windows125%／150%实机缩放、全部皮肤及实际硬件合成尚未逐一验证。年视图数百块砖仍需放大导出图查看细字。
