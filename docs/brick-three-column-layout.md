# 工时积木三栏落地（2026-11-15）

- 左栏：周期工时、记录日、日均；人物与对话保留在下方。
- 中栏：完整日期/月列；月度按小时、年度每天一块；统一砖红实心砖，砖面日号按真实日期绘制。
- 右栏：最长工作日、最忙月份（年度）/最忙周（月度，仅统计当前月记录）、最早开始、最晚结束、最长自然日连续记录。使用轻图标和细分隔线，不使用卡片背景。
- 月度无故事卡；年度只有选择后显示悬浮故事，开关不改变三栏画布。
- 下载/复制共用1920×1080三栏绘制，带品牌与标题；不再导出过时的右侧大背景卡或工作剪影。
- 没有记录时显示暂无/破折号；不拿AI预览图内数字当真实数据。
- 计时、采集、数据库、AI生成和历史记录没有修改。

核心文件：brickArtwork.ts（共享画布）、brickChart.ts（布局与命中）、brickHighlights.ts（只读展示汇总）、BrickDashboard.tsx及brickDashboard.css。

验证：类型及生产构建、修改TS文件ESLint、test-brick-chart、test-brick-stats、test-brick-highlights通过。隔离Electron界面测试覆盖1366×768、1440×900、1920×1080、1120×760、480×900，月度无故事、年度浮层不重排、画布点击与辅助按钮、16:9复制/下载逐字节一致。检查年度界面和实际导出：三栏边界、统一背景、数字层级、日期命中、无默认故事卡、无横向溢出。

边界：桌面窗口为主要目标；很窄窗口的密集31日标签和砖面日号会缩小。材质为现有砖面素材与代码倒角光影，不是把AI整张预览图直接贴成页面；AI图里的逐块细节不承诺像素一致。构建仍有既存的大chunk提醒。本轮没有打包或发布。
