# Didly 英文品牌名

展示英文名统一为 `Didly`，中文名保留“干啥了”。

使用统一 BrandWordmark 组件：中文在上，英文在下，英文小两档（每档 2px，合计 4px）；通过五个字母的均匀间距匹配中文行宽，不拉伸字形。继承所在品牌位置的字体和颜色。

应用位置：启动页、登录页（桌面和窄屏）、侧栏品牌、关于页、工时积木页品牌和页脚；两种下载海报也包含上下排版的品牌名。替换这些展示区域旧的 Ganshale/GanShaLe 名称。普通语句中的“干啥了”不是品牌字标，不强行插入英文行。

不改 Electron appId、安装目录、数据库名、存储键、系统窗口标题或卸载信息，避免影响现有安装与历史数据。

验证：构建及本轮相关文件 ESLint；scripts/test-brand-wordmark.cjs 使用不启动原生采集器的隔离 Electron，断言英文内容、上下位置、两行宽差小于 1px、主要品牌字号差 4px，并检查两种比例 PNG 导出。极小字号处保留 8px 下限。
