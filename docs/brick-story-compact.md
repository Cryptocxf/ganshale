# 砖块故事紧凑布局

- 顶部改为左侧小砖图，右侧日期、工时、等级；使用 CalendarDays、Clock3、Layers 图标。
- 默认卡片不滚动、不分页；工作总结最多显示两行，完整内容可在详情弹窗中查看及选择复制。周期之最和完整软件榜也保留在详情弹窗。
- 当日榜维持原序号、图标和彩色条形，缩小行间距；矮窗口采用 26px 行高。
- 不修改工时数据、采集或后台调度，也不改变海报导出的数据和比例。

验证：构建通过，BrickDashboard ESLint 通过。隔离测试 scripts/test-brand-wordmark.cjs 使用五个应用及超过200字的长总结，检查 1120×760 和 1440×900：五行均位于卡片边界内、scrollHeight 不超过 clientHeight、图片在信息左侧、三种信息图标存在；完整总结入口及两种 PNG 导出通过。
