# 白领搬砖视觉更新（2026-11-14）

本轮只调整搬砖页和两种导出图的视觉，不修改后台计时、数据库或 AI 调度。需求由 project-prompt-refiner 整理：白领领带人物、低装饰材料、砖面左上等级及中央大日期，具体时长继续保留在统计、图例和故事中。

## 素材及生成提示词

使用内置 image_gen（非 CLI）。下列均为项目实际引用的独立版本，不覆盖旧素材。

- `public/brick-whitecollar-v1.png`：透明 2×2 人物图集。同一位中国男性白领，象牙白衬衫、海军蓝领带、炭灰西裤、黑皮鞋；克制精致的哑光 3D 形象。依次为从容站立、松领带擦汗、坐凳疲惫、自然站立。全身包含鞋子，格内留白，不含工具带、安全帽、施工服、文字或场景。根据月/年累计工时选择前三种状态。
- `public/brick-front-minimal-v2.png`：透明 4×4 图集，前 13 格为严格正交正面砖块，余格为空。依次为实心陶土、双孔、多孔、弧纹陶土、石灰石、精工孔砖、花岗岩、水磨石、大理石、拉丝赤铜、秘银、哑光金、深色铁。材质细节低对比、细小倒角，不要破损、厚重雕花、印章、文字或数字。代码按实测素材边界裁切，日期和等级由 Canvas 绘制而非图片烘焙。
- `public/brick-catalog-minimal-v2.png`：相同 13 种材料，透明 4×4 等格，微俯视三维产品图，余格为空；统一尺寸与柔和棚灯，完整物体留在各格，光滑克制、无脏污、无装饰边框、无文字、无乐高凸点。用于图鉴及故事，不用于冒充正面砖面。

## 验证范围

- TypeScript + Vite 构建通过（仍有既有的大 chunk 提示）。
- 本轮相关三个 TS/TSX 文件 ESLint 通过。
- brick-stats 回归通过：日期边界、去重、等级区间、0–366 块布局。
- 隔离 Electron 回归覆盖 13 级独立素材、六列详情卡片、两种窗口尺寸和精确 1920×1080 / 1080×1920 月/年导出；不使用用户真实历史数据。
- 素材提示词以上列生产约束记录；生成源位于 Codex generated_images，应用仅引用 public 下版本。

年视图砖块较多时仍需要放大导出图查看单砖日期；完整工时可点击故事查看。本轮不打包、不发布。
