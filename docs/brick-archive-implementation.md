# 搬砖档案页与双比例分享图

日期：2026-11-13。仅本地实现，未打包、未发布。

## 已实现

- 采用用户确认的暖纸色、赤铜数字、细线分栏、鼠尾草条形图；搬砖页导航单独使用文字与下划线，不修改其他页面导航。
- 真实正面砖图、日期＋实际工时、累计时长、记录天数、日均和超8小时天数。每个正时长日期一块砖，时长递减从底层排起，点击或键盘选择查看故事。
- 故事读取当天已保存的工作记录，不发起新模型请求。应用排行只使用应用名称、时长，不包含窗口标题。
- 13级材质图鉴保留六列详情弹窗。
- 下载菜单：16:9（1920×1080）、9:16（1080×1920）。独立canvas重排，支持浏览器和桌面客户端，不拉伸客户端截图；包含本期之最、TOP5、工作剪影和时长图例，不包含操作控件。
- 本期之最：最长一天、最早/最晚记录、自然日最长连续记录、超12小时天数。最早/最晚按本地自然日的记录边界统计；跨到次日零点显示“次日00:00”，不认定为上下班或法定加班。
- 应用时长单独合并重叠区间；明确提示与办公总时长口径不同，不能强行让两者相等。
- 日度办公时长继续使用现有 officeElapsedForDay；仅只读展示层按本地自然日裁切记录。月份查询回看前一日，以纳入常见跨日工作会话。未修改后台采集或数据库写入逻辑。

## 验证

- `npm run build`：通过（仍有原有打包块体积提醒）。
- 针对 BrickDashboard、brickStats、brickArtwork 的 ESLint：通过；不等于全仓库lint清零。
- `test-brick-stats.cjs`：通过。覆盖跨午夜、跨月边界、重复ID、未来/本客户端排除、等级边界、0—366块排层。
- `test-background-recording.cjs`：通过。实际点击下载菜单，校验月度及365日年度的两种PNG像素尺寸；图鉴、月份/年度切换、最小化/冻结、锁屏/休眠恢复、托盘关闭继续计时通过。
- `test-timing.cjs`、`test-foreground-sampler.cjs`：通过。
- `test-window-recorder.cjs`、`test-window-store.cjs`：最初受沙盒EPERM/ACL影响失败，在正常Windows权限下复测通过。不能据此声称历史EPERM问题已经修复。
- 实际客户端及导出图片已肉眼检查；隔离测试样例、365日数据和截图仅保存在 `.private`，没有写入真实用户数据库。

## 边界

- 只有记录天数，不假称法定工作日数；没有记录不补砖，没有总结不编造。
- 年度数百块砖的全景文字天然较小，客户端仍可点击单砖查看详细工时。
- 当前只有测试环境验证，不包含新版安装包升级/发布验证。
